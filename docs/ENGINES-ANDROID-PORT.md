# Engine changes Android must port (persona evaluation work)

Source of truth: the Swift files named below; behaviour is pinned by shared fixtures.

1. Name cleaning (`ArtworkNameCleaner`), checked by `artwork/fixtures/name-cleaning.json` (5 new cases at the end):
   - Before the pipe-prefix rule, remove a trailing release group, case-insensitive: `[-.\s](yify|yts([. ]mx)?|rarbg|etrg|mkvcage|fgt|ntb|tgx)\s*$` (so `1080p-YIFY` loses the group and the tag is then removed as usual).
   - Tail loop, before the existing "Season N" rule: drop a token `^\d{1,2}x\d{1,3}$` (1x02); drop the last two tokens when the last is `^\d{1,3}$` and the one before is `episode`, `ep`, `episodio` or `folge` (needs more than 2 tokens left).
2. Spelling correction (`SpellingIndex`, `SmartSearch.swift`), checked by the vocabulary cases in `SmartSearchTests.swift` and the equivalence test `SpellingIndexEquivalenceTests.swift`:
   - Build once from the vocabulary: sorted words (prefix test by binary search, replaces the whole-vocabulary prefix scan), words by first letter + length, words by `dropFirst().prefix(3)`, and fold key -> commonest word (`ArtworkMatchDecision.fold`, ties by earlier word).
   - Order for a word of 4+ letters that is not in the vocabulary and not a prefix: (a) fold-key match (transliteration spelling) -> that word; (b) edit distance (limit 1 up to 5 letters, else 2) among words with the same first letter and length within the limit; best = smaller distance, then higher count, then alphabetical; (c) if none and the word has 5+ letters: words with the same 3 letters after the first, length within 1, different first letter, distance 1.
3. Guide channel names (`ChannelNormalizer.name`): before the "+N" variant rule, remove a bracketed copy marker `[\(\[]\s*(backup|back-up|alt|alternate|mirror|raw|reserve)\s*\d{0,2}\s*[\)\]]` (case-insensitive). No shared mapping case was added yet (add one with its exact confidence once the Apple run shows it).
4. Match decision (`ArtworkMatchDecision.languageCodes`): the table now covers the 23 persona languages plus dutch, polish, persian, hebrew, vietnamese, odia, assamese, nepali, sinhala, malay, tagalog. Port the same table (language word -> the details service code); it only breaks ties between equally good results.
5. Persona evaluation (`tools/personas/`) is Apple-side only; Android can reuse the generated corpus JSON to run its own matcher and search.

## Second round (persona evaluation, matcher recall 66-84% -> 84-96%, guide wrong rate 14-28% -> 1-2%)

Pinned by `artwork/fixtures/name-cleaning-persona.json` (name cleaning) and `epg/fixtures/mapping-persona.json` (guide mapping, same format as `mapping-cases.json`), both read by `PersonaFixesTests.swift`. Nothing here is tuned to one library or language.

6. Name cleaning (`ArtworkNameCleaner.parse`), in this order inside the existing rules:
   - After bracket removal and "|" padding: turn a dot that touches an episode marker into a space (`\.(?=S\d{1,2}E\d{1,3}\b)` -> " ", and `(\bS\d{1,2}E\d{1,3})\.(?=\S)` -> "$1 "), case-insensitive, so `Show.S03E17.1080p` and `x265.S04E10` end in a marker the tail rules can see.
   - Rule 2 (dots to spaces) also applies per word when the name has spaces: a word with two or more dots, at least two parts of 2+ letters and at most one one-letter part is split on the dots (`KO.-.The.Delicious.Guys.[2015]`); initials such as `M.S.` stay. Do this before the bracket rule.
   - Head loop: a four-digit year (1900-2030) that is the first word, followed by a standalone `-` or `|` and at least one more word, is dropped and becomes the year to search with when none is known (`TA - 2021 - Title`, `2019 - Title`). It runs inside the same loop as the prefix rule, so `IN| 2024 - Title` and `2019 - EN - Title` both work.
   - Prefix code list: added `ja ko zh th id vi fa he sv da fi el cs hu ro bg sr hr sk sl sa ae qa eg sg my ph za ng ke nz ie se dk gr at ch be` (only read when followed by a separator, as before).
   - Release group (end of name) list: added `psa evo ntg ion10 sparks cmrg galaxytv eztv ettv rartv mkvking tigole qxr megusta pahe`.
   - Tail loop, after the `Episode N` rule: drop the last two tokens when the last is `^\d{2,3}$` and the one before is `-` and more than two tokens remain (absolute episode number `Dororo - 070`). Four digits are never dropped here (`Blade Runner - 2049` keeps its number).
7. Lookup retry (`MetadataMatchService.lookup`): after the first search and the year search fail, if the cleaned name has 2+ words and ends in a four-digit year (1900-2030) left on the end (`Hospital Playlist 2020`), search again without it and decide with that year (the library's year wins). This runs before the "drop the last word" retry.
8. Channel names (`ChannelNormalizer.name`): up to two country prefixes are read (`US| US: MTV`); the first is kept as `countryPrefix`. New `withoutFeedWord(key)`: when the last word is one of `east west north south london live` and one word or more would remain, the key without it.
9. Guide mapping (`GuideMappingEngine`), the per-channel body is now a function with a `trustIDs` flag:
   - New step 6b, after step 6 (equal name) and before fuzzy: if the full name has no equal-name entry, try the name without its feed word (`CNN East` -> `CNN`); same country compatibility and `narrow`; method `name`, confidence `min(0.89, 0.65 + bonus)`. A name the guide lists as it is (`HBO East`) is matched as before.
   - Id guard, only for matches by an id found in another source (`exactOther`) or by a normalised id (not the playlist's own guide: shared case 46 stays): if the matched guide channel has no name key that shares a word with the channel's name and has the same set of number words (`ESPN 2` is not `ESPN`, `RAI 1` is not `La 1`), map the channel again with ids switched off; use that result when it is a `name` or `alias` match, else keep the id match.
10. Measured but not changed (Smart Mix): cross-row duplicates are 15-23% only for libraries under about 500 titles (the same few titles fill every genre shelf), restricted leaks 0, empty shelves 0 except libraries with no genre or language data (their genre and language shelves cannot exist). The genre selection rules are pinned by `genre-shelves.json` on both platforms, so they were left alone.

## Third round (spelling variants; measured with the persona harness, matcher only)

11. `MetadataMatchService.lookup`, last step, only when none of the searches returned any result at all (`seen` empty; the existing refused-match tests stay at their request counts): up to two more searches with `spellingVariants(text)`, each followed by the usual decision (decided against the ORIGINAL cleaned name, so the phonetic similarity must still accept). `spellingVariants`: fold diacritics, lower-case; none unless the name is ASCII with 5+ letters. Variant A: `aa->a ee->e oo->o ii->i uu->u`, then one letter of a doubled consonant `([b-df-hj-np-tv-z])\1 -> \1`, then drop an `h` that follows `t d b k g p` at the end of a word's prefix (`\b([a-z]*[tdbkgp])h -> \1`). Variant B: same with `ee->i oo->u ou->u ae->e ay->ai`. Only variants that differ from the name, in the order A, B. Effect on the persona corpus: translit 47% -> 64%, wrong rate unchanged (0.1% overall).
12. Home display titles: `FeaturedService.displayTitle` is `ArtworkNameCleaner.clean(raw)` (empty -> raw); tiles pass the library year to the cleaner (`DisplayTitle.labels` with year), so "Arcane 2021" under a 2021 tile shows "Arcane".
13. Measured and deliberately NOT done: a one-year tolerance for short titles (the shared decision fixture says a short title needs its exact year even when it is the only film of its name: Pushpa 2021 vs 2022, Jawan 2023 vs 2022); a popularity tie-break for undated titles (research: wrong rate 0.01% -> 0.04%); the `language=hi-IN` retry (live probes: it only localises titles, no extra matches); `token_set_ratio` as an accept score (100 for any subset). Absolute-episode mapping to season/episode through episode groups was not built.

## Fourth round (ceiling measurement; conditional series trust)

14. FINAL owner policy, name only (supersedes every year, language and popularity rule above, 13 included): `ArtworkMatchDecision.decide` reads only the cleaned name. Walk the candidates in result order; the first whose title or original title equals the cleaned name token for token (`canon`, not phonetic, not via a subtitle head) wins; otherwise the best name score >= 0.88 (existing fold, skeleton, head, near-spelling tiers; ties by result order). No year, language, runtime or popularity is read (`Query.year/languageTag` stay in the signature, unused). Lookup: one search by the cleaned name for the kind (movie or tv), no year search; then trailing-year strip, without the last word, without the first word, spelling variants A-D (v read as w; triple letters cut) up to 3, only when nothing came back. Provider-supplied database ids still first. Kotlin: `decide` in `ArtworkMatchDecision.kt`, year search removed from the Kotlin matcher file. Fixtures: `match-decision.json` (changed ids and reasons in `artwork/fixtures/README.md`, new ids 9060-9065), `name-cleaning-persona.json` (two new release-group cases). Name cleaner: an attached release group is removed anywhere (`\s*-(group)(?=[\s.\[(]|$)`, same list as the end-of-name rule) before the end-of-name rule; Kotlin `ArtworkNames.kt` has it and the longer group list.
15. Measured ceiling (persona corpus, 47,150 gold labels, all present in the index): only 0.5% are inherently ambiguous (same normalised title within the year window; 1.6% for no-year, 1.8% for absolute-episode). So the achievable recall is about 99.5%; remaining misses are policy refusals of short film names (no year / year off), transliteration beyond edit distance 1, and release-group leftovers.
16. Measured with the name-only policy (persona harness, 22k rows): misses 1649 -> 420; wrong matches 8 -> 107 (0.48%), nearly all same-name remakes or namesakes (Kasauti Zindagii Kay 2001/2018, Doraemon, Hope, Dragon, Beast): the accepted cost of ignoring year. Live channel logos were not changed (the logo lookup lives in UI files that were off limits during the run).
