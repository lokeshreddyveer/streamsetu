## In every app

- **Plex pictures no longer carry your access token in their address.** The token is sent as a header, only to your own Plex server. Addresses saved by an earlier version are cleaned the first time the app opens.
- **Logins and tokens stay with their server:** if a link redirects to a different server, the token and key headers are dropped. Pictures and streams from your own server are unaffected.
- **Privacy text:** it now lists OpenSubtitles and explains how tokens and the phone-assisted setup are handled.

## Fire TV, Android TV, Android phone and tablet 0.10.1

- **Release builds** can no longer be signed with the debug key by mistake.
- **Long-press menus:** the press that opened a menu is recognised exactly, so holding OK for any length, with or without key repeats, never also chooses the first item.
- **Phone-assisted setup:** a longer one-time code, checked safely, and a note on the screen that it is not encrypted, so use it on your own Wi-Fi.
- **Background playback:** the app records a failed start of the playback service instead of hiding it. Playback releases its network watcher when it ends.

## Mac and iPhone

- Plex picture cleanup and token handling, as above.
