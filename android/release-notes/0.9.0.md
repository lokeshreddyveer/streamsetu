**StreamSetu __VERSION__ for Fire TV / Android TV and for Android phones and tablets**

Two downloads, with the same build inside. Pick the one for your device:

- `StreamSetu-FireTV-__VERSION__.apk`: for a Fire TV or Android TV (remote layout).
- `StreamSetu-Android-__VERSION__.apk`: for an Android phone or tablet (touch layout).

Both are signed with the StreamSetu release key. SHA-256 of each file (they are the same file): `__SHA256__`

What is new
- **More like this, much better:** a movie or series now suggests titles by franchise (sequels and other films of the series), director, genre, shared cast and a similar story, with the reason under each poster ("Same director", "Similar story" and so on). It looks in other folders too, not only the open one, and never lists another language copy of the same title. The Fire TV, phone and tablet screens for movies and series all have it.
- **Fire TV:** Back with the player controls showing hides them first; a second Back asks about leaving. Holding Up in the folder list stops at the first folder instead of running on into the buttons above. The folder search field now appears only on Live TV, where the list is longest.
- **Opening screen and Settings** (from 0.8.0): a library picker, redesigned Settings with switches, the folder highlight staying in one place.

Not yet tried on real equipment: Jellyfin, Emby, Plex, tuners, WebDAV, Chromecast, skip intro and reminders. Please tell me if anything misbehaves.

Install: on a Fire TV, use Downloader or ADB. On a phone, open the file and allow installs from this source. The app can also update itself from this page (Settings, About, Updates).

StreamSetu is a player only. It includes no channels, movies or series.
